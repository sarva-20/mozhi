# Mozhi Recording Script — Volunteer 03

## How to record

- **Device:** Any phone voice-memo app works fine.
- **Format:** Save as `.m4a`, `.wav`, or `.mp3`.
- **Environment:** A normal room is fine — doesn't need to be silent.
- **Length:** One continuous recording, 2–3 minutes.
- **Pace:** Speak at your normal, everyday pace — don't slow down or over-pronounce. Say it like you're casually mentioning it to a coworker.
- **Mistakes:** If you stumble, just keep going or restart that one line — don't stop the recording.

## Part A — Read these sentences naturally, in order

- The scheduled reboot didn't actually apply the pending updates.
- We rolled back the release because the checkout flow was throwing errors.
- The monitoring dashboard hasn't updated in almost twenty minutes.
- The new switch hasn't shown up in the network inventory yet.
- The webhook stopped firing after we rotated the signing secret.
- Someone needs to check why the antivirus keeps quarantining that installer.
- The vendor's API changed the response format without any warning.
- Nobody documented how the old cron job was supposed to work.
- We need to update the DHCP settings on the new router.
- The config drifted between environments again after the last change.
- Someone needs to review the access logs from that suspicious login.
- The support team needs read access to that log bucket.

## Part B — Say each of these acronyms out loud, the way you'd naturally say it

- MFA
- TLS

- SDK

## Submitting

Save the recording and send it back. No need to write anything else — just the audio file.

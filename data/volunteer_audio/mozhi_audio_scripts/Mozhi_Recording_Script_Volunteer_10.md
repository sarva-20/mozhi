# Mozhi Recording Script — Volunteer 10

## How to record

- **Device:** Any phone voice-memo app works fine.
- **Format:** Save as `.m4a`, `.wav`, or `.mp3`.
- **Environment:** A normal room is fine — doesn't need to be silent.
- **Length:** One continuous recording, 2–3 minutes.
- **Pace:** Speak at your normal, everyday pace — don't slow down or over-pronounce. Say it like you're casually mentioning it to a coworker.
- **Mistakes:** If you stumble, just keep going or restart that one line — don't stop the recording.

## Part A — Read these sentences naturally, in order

- That's a reasonable timeline, let's confirm it with the client tomorrow.
- The load balancer is sending too much traffic to the second node.
- I think we're hitting a rate limit on the third-party service.
- That report took forever to run, the query needs an index.
- Can you check if the backup job actually completed last night?
- We think the outage was regional, not just our data center.
- The access request is stuck in approval because the manager's out.
- The new hire still doesn't have access to the shared drive.
- We think there was a credential stuffing attempt overnight.
- We need a rollback plan in case the deployment goes sideways.
- Someone should check if the replication lag is affecting reporting.
- The scanner flagged an outdated library in the dependency tree.

## Part B — Say each of these acronyms out loud, the way you'd naturally say it

(One at a time is fine — you don't need to build a sentence around these.)

- URI
- CPU
- POP3
- JSON
- CD
- SATA
- CVE

## Submitting

Save the recording and send it back. No need to write anything else — just the audio file.

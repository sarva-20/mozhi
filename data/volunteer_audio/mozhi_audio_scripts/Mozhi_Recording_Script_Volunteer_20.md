# Mozhi Recording Script — Volunteer 20

## How to record

- **Device:** Any phone voice-memo app works fine.
- **Format:** Save as `.m4a`, `.wav`, or `.mp3`.
- **Environment:** A normal room is fine — doesn't need to be silent.
- **Length:** One continuous recording, 2–3 minutes.
- **Pace:** Speak at your normal, everyday pace — don't slow down or over-pronounce. Say it like you're casually mentioning it to a coworker.
- **Mistakes:** If you stumble, just keep going or restart that one line — don't stop the recording.

## Part A — Read these sentences naturally, in order

- Can we schedule a maintenance window for the database migration?
- The QA team found a regression in the search results ranking.
- The backup restored fine, but the indexes need to be rebuilt.
- That report took forever to run, the query needs an index.
- We should stagger the update rollout instead of pushing it everywhere at once.
- Nobody documented how the old cron job was supposed to work.
- Someone accidentally deleted the staging database this morning.
- The test environment doesn't have the same data volume as production.
- We're seeing a memory leak whenever the batch job runs overnight.
- The migration script left a few orphaned records in the old table.
- The report generator times out whenever the date range is too wide.
- The client wants a status update before the change window closes.

Save the recording and send it back. No need to write anything else — just the audio file.

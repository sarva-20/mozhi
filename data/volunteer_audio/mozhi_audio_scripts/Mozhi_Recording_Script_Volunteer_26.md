# Mozhi Recording Script — Volunteer 26

## How to record

- **Device:** Any phone voice-memo app works fine.
- **Format:** Save as `.m4a`, `.wav`, or `.mp3`.
- **Environment:** A normal room is fine — doesn't need to be silent.
- **Length:** One continuous recording, 2–3 minutes.
- **Pace:** Speak at your normal, everyday pace — don't slow down or over-pronounce. Say it like you're casually mentioning it to a coworker.
- **Mistakes:** If you stumble, just keep going or restart that one line — don't stop the recording.

## Part A — Read these sentences naturally, in order

- We need to whitelist that IP before the integration test will pass.
- Can you restart the Docker container and see if that clears it up?
- The support queue jumped overnight, must be tied to that outage.
- The alert fired three times before anyone actually looked at it.
- Support said they'd follow up on the SLA breach by end of day.
- The new switch hasn't shown up in the network inventory yet.
- The old server room still isn't on the new cooling schedule.
- Can someone confirm the maintenance ticket actually went through?
- The new employee still can't print from the third floor.
- That report took forever to run, the query needs an index.
- We're not seeing the new build reflected on the staging server yet.
- The reporting server keeps running out of temp space during the export.

## Part B — Say each of these acronyms out loud, the way you'd naturally say it

(One at a time is fine — you don't need to build a sentence around these.)

- RBAC

- SLA
- CD
- OS
- SAN

## Submitting

Save the recording and send it back. No need to write anything else — just the audio file.

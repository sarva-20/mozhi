# Mozhi Recording Script — Volunteer 06

## How to record

- **Device:** Any phone voice-memo app works fine.
- **Format:** Save as `.m4a`, `.wav`, or `.mp3`.
- **Environment:** A normal room is fine — doesn't need to be silent.
- **Length:** One continuous recording, 2–3 minutes.
- **Pace:** Speak at your normal, everyday pace — don't slow down or over-pronounce. Say it like you're casually mentioning it to a coworker.
- **Mistakes:** If you stumble, just keep going or restart that one line — don't stop the recording.

## Part A — Read these sentences naturally, in order

- That's honestly a cleaner way to structure the config files.
- The migration script left a few orphaned records in the old table.
- Someone left the debug logging turned on in prod, that's filling up the disk.
- Can you double check the subnet mask on that new server?
- We're still waiting on the vendor to confirm the maintenance window.
- The new switch config didn't get saved before the power blip.
- The old ticketing system is being retired at the end of the quarter.
- We're not seeing the new build reflected on the staging server yet.
- The audit trail shows someone deleted those records on purpose.
- Can we get someone from networking on this call, it's their subnet.
- Can you confirm the new hire's badge access was set up correctly?
- The old server room still isn't on the new cooling schedule.

## Submitting

Save the recording and send it back. No need to write anything else — just the audio file.
